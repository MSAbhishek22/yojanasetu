Officer Dashboard

Totals across all (synthetic) departmental registers, enrolment by district and scheme, duplicate flags, and the inclusion gap — people eligible for a scheme they are not enrolled in.

District map — enrolment volume as height

Click a block (or Tab to it, then Enter) to filter the whole dashboard to that district. Block height = enrolment volume in that district. Drag the map with the mouse, or press Alt+← / Alt+→, to rotate the scene ±20°; plain ←/→ move focus between blocks. “Reset view” restores the default angle; “Flat map” switches to the 2D district list below. Rotation is off on touch screens, so a scroll gesture is never hijacked. A plain 2D list follows for screen readers and reduced-motion users.

    Beneficiary Lookup

    Search by synthetic ID (e.g. YS-1001), name (e.g. Gita Devi) or district (e.g. Dehradun). One holistic view shows every scheme enrolment for that person, each with its source department and record ID.

    Try: YS-1001 · Ramesh Singh · Nainital — the seeded duplicate and near-miss pairs.

    Duplicate Detection

    Deterministic matching on name + date of birth + district + family reference. Every flag shows its evidence — which records match, on which fields, with a confidence score — and a suggested action. Nothing is auto-merged.

    Duplicate Review Queue

    Every flagged duplicate pair, waiting for a human decision. The detecting engine only suggests — an officer decides: Confirmed duplicate or Not a duplicate, with an optional note. Each decision is written to the audit trail below. Decisions are held in server memory for this demo session only and are never auto-merged into any register.

    Audit trail — officer decisions (newest first)

    Eligibility Trace

    Pick a person and a scheme. Every rule is shown PASS / FAIL / UNKNOWN with the source record it was read from, and a final verdict: ELIGIBLE, NOT ELIGIBLE, or NEEDS REVIEW.
